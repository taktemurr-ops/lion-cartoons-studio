# Lion Cartoons Studio 🦁

Özgün, yaşa uygun, çok dilli çocuk animasyonu üretim projesi. YouTube kanalı: @LionCartoonsWorld.

## İlk teslim
- Senaryo: Lion Kids S01E01 — Leo ve Kayıp Gökkuşağı.
- Kanal görselleri: doğru ölçülerde oluşturulmuş; kaynak ZIP paketi sohbet üzerinden teslim edilir.
- YouTube yükleyici: OAuth gerektirir; varsayılan kontrol modu ve gizli yayın.
- **Henüz gerçek tam animasyon veya otomatik video yükleme tamamlanmadı.**

## Güvenlik
- Küfür, cinsel içerik, korkutucu/aşırı şiddet içeren içerikler yok.
- Başkalarının müzik, karakter, çizim, video veya senaryolarını kopyalama yok.
- Yayın öncesi insan kontrolü ve çocuklara özel içerik sınıflandırması zorunlu.
- client_secret.json, token.json veya diğer kimlik bilgilerini depoya koymayın.

## GitHub depo görünürlüğü
**DİKKAT:** Depo denetimde PUBLIC olarak göründü. Özel kalmasını istiyorsanız GitHub > Settings > General > Danger Zone > Change repository visibility > Private yapın. Kanala ait gizli verileri/public depoya yüklemeyin.
